Analysis details

The cTWAS analysis was performed using run_ctwas.R located at /project/xinhe/xsun/AD_jubao/3.ctwas/run_ctwas.R.

Key steps:

  1. GWAS preprocessing: GWAS summary statistics from Bellenguez et al. 2022 were read and preprocessed with read_gwas() and preprocess_z_snp() (dropping multi-allelic and strand-ambiguous variants).
  2. Weight preprocessing: Prediction weights (PredictDB format, RASQUAL-based) were preprocessed with preprocess_weights() for each condition (naive, SL1344). For eQTL, protein-coding gene filtering was applied; for caQTL it was not.
  3. Gene z-score computation: Gene-level z-scores were computed with compute_gene_z().
  4. Region data assembly: Region data was assembled with assemble_region_data() using thin = 1 and adjust_boundary_genes = TRUE.
  5. Parameter estimation: Parameters were estimated with est_param() using group_prior_var_structure = "shared_all", null_method = "ctwas", niter_prefit = 3, niter = 30, min_gene = 1, min_var = 2, min_p_single_effect = 0.8.
  6. Fine-mapping: Fine-mapping was performed with finemap_regions() using L = 5 and null_method = "ctwas".

LD reference: UK Biobank LD reference (b38) stored at /project2/compbio/UKB_LD_REF/UKB_LDR_0.1_b38/.

Weight files (RASQUAL-based):

  • caQTL: caQTL_naive_RASQUAL.db, caQTL_SL1344_RASQUAL.db
  • eQTL: eQTL_naive_RASQUAL.db, eQTL_SL1344_RASQUAL.db

Peak Sets

A peak set is defined as all caQTL peaks that belong to the same credible set (CS) within the same LD region. The PIP of a peak set is the sum of the individual peak PIPs.

peaks_in_cs_caQTL <- fm_caQTL[fm_caQTL$type == "caQTL" & !is.na(fm_caQTL$cs), ]

mapping_caQTL <- readRDS("/project/xinhe/xsun/AD_jubao/data/QTL_pmid29379200/ATAC_peak_mapping.RDS")
peaks_annot_caQTL <- merge(peaks_in_cs_caQTL, mapping_caQTL, by = "molecular_id", all.x = TRUE)

peak_sets_caQTL <- do.call(rbind, lapply(
  split(peaks_annot_caQTL, list(peaks_annot_caQTL$region_id, peaks_annot_caQTL$cs), drop = TRUE),
  function(x) {
    region_parts <- strsplit(x$region_id[1], "_")[[1]]
    data.frame(
      region_chr   = as.integer(region_parts[1]),
      region_id    = x$region_id[1],
      cs           = x$cs[1],
      n_peaks      = nrow(x),
      sum_pip      = sum(x$susie_pip),
      peaks        = paste(x$molecular_id, collapse = ", "),
      contexts     = paste(x$context, collapse = ", "),
      peak_coords  = paste0("chr", x$chrom, ":", x$start, "-", x$end, collapse = "; "),
      stringsAsFactors = FALSE
    )
  }
))
